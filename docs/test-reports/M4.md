## 1. Summary of Implemented M4 Components

1. **Asynchronous File-Context Enrichment (`crates/radivine-core/src/enrich.rs`, `context.rs`):**
   - Implements the two-tier `BasicContext` (zero-I/O visibility) + `FileFacts` (asynchronous enablement) model (`ACTION_SYSTEM.md` §4).
   - Performs `std::fs::symlink_metadata` and `std::fs::metadata` to distinguish `Regular`, `Directory`, `BrokenSymlink`, `Missing`, `Fifo`, `Socket`, `CharDevice`, `BlockDevice`, and `Other` (`symlink[i]` recorded per item).
   - Safely opens regular files with `rustix::fs::openat(..., OFlags::RDONLY | OFlags::NONBLOCK | OFlags::CLOEXEC)` and verifies `fstat` is still a regular file before reading up to `8 KiB` (`SNIFF_BUFFER_BYTES = 8192`). Never opens FIFOs, sockets, or device nodes.
   - Implements the full text vs. binary decision tree: UTF-8/UTF-16 BOM detection, 23 magic-number binary signatures (ELF, PDF, PNG, JPEG, GIF, WebP, ZIP, gzip, bzip2, XZ, Zstd, 7z, RAR, TAR, Ogg, FLAC, MP3, WAV, RIFF, SQLite, WASM, Mach-O, Java class), NUL byte check, UTF-8 boundary-tolerant validation (`up_to >= len - 3`), and control-byte ratio heuristic (`<= 2%`).
   - Enforces `MAX_ENRICHED_ITEMS = 64` and a hard `1500 ms` session watchdog deadline via a dedicated timer thread + `Condvar`, transitioning remaining `Pending` items (`"Checking…"`) to `"Couldn't inspect the file"` without blocking the UI thread or mutating wheel geometry.

2. **X11 `CLIPBOARD` Selection Ownership Service (`crates/radivine-platform/src/x11/clipboard.rs`):**
   - Owns a dedicated unmapped `1×1 InputOnly` X11 window (`clip_win`) and claims `CLIPBOARD` via `SetSelectionOwner`.
   - Responds to `SelectionRequest` for:
     - `TARGETS` (advertising `TARGETS`, `TIMESTAMP`, `MULTIPLE`, `SAVE_TARGETS`, `x-special/gnome-copied-files`, `text/uri-list`, `UTF8_STRING`, `text/plain;charset=utf-8`, `text/plain`, `STRING`)
     - `x-special/gnome-copied-files` (`copy\nfile:///...` without trailing newline, matching Nemo's exact paste parser)
     - `text/uri-list` (`file:///...\r\n`)
     - `UTF8_STRING` / `text/plain;charset=utf-8` / `text/plain` / `STRING` (newline-separated local paths)
     - `MULTIPLE` atom pairs and multi-chunk `INCR` transfers for payloads exceeding `256 KiB`.

3. **Context-Aware Built-in Actions, D-Bus Integration & Custom Actions (`crates/radivine-actions`):**
   - `PreviewPlaceholderAction` (`radivine.preview.full`, `radivine.preview.head`, `radivine.preview.tail`): full M4 two-tier visibility + `FileFacts` enablement (`"Checking…"`, `"Select a single file to preview"`, `"Folders can't be previewed"`, `"Broken link"`, `"File not found"`, `"Special file"`, `"No permission to read"`, `"Not a text file"`, `"Couldn't inspect the file"`). Remains a clearly identified M5 placeholder on execution (`radivine-viewer` is scheduled for M5).
   - `CopyAction` (`radivine.copy`): emits `Outcome::Effects(vec![Effect::SetClipboard(...)])` for single files, multi-file selections, and directories without modifying source files.
   - `PropertiesAction` (`radivine.properties`): invokes `org.freedesktop.FileManager1.ShowItemProperties` over the session D-Bus wire protocol (`crates/radivine-actions/src/dbus.rs`), falling back to a clear error notification (`"File manager doesn't support properties"`) if unavailable.
   - `CustomAction` (`crates/radivine-actions/src/custom.rs`): parses and validates `$XDG_CONFIG_HOME/radivine/actions.toml` (`[[action]]` and `[menu]` `hide`/`order` overrides) with 1-based line/column diagnostics, whole-argument placeholder expansion (`{path}`, `{paths}`, `{uri}`, `{uris}`, `{dir}`, `{name}`), direct `Command::new(program).args(...)` execution (never `sh -c`), `cwd`, `per_item`, `wait`, `notify` (`never` | `on-error` | `always`), and `[action.when]` (`scheme`, `count`, `mime`, `extensions`, `require_text`).

4. **Session Controller & Daemon Wiring (`apps/radivine`):**
   - Connects `Enricher` and `Dispatcher` (max 4 concurrent jobs, `catch_unwind` panic isolation, pre-dispatch enablement re-check) to the `calloop` event loop via wakeup callbacks.
   - Applies live `WheelSession::set_enabled` updates without altering segment positions or wheel geometry.
   - Executes `Effect::SetClipboard` on the X11 UI thread and dispatches `Effect::Notify` / job error notifications via `org.freedesktop.Notifications.Notify`.
   - Supports hot-reloading both `config.toml` and `actions.toml` via `radivine reload` (`SIGHUP` / CLI), preserving the active `ActionRegistry` if `actions.toml` fails validation.
