## Product accuracy and evidence

Before edits, reviewed AGENTS.md, the complete website plan, W0 contract, W1/W1.5 components, styles, tests and reports. Claims were checked against Rust CLI/configuration/action/platform/preview/conversion/worker/Control Center code, tests, packaging files, README/CHANGELOG, decisions/design notes, contribution/security/notices files and N5/release reports. Evidence URLs pin the audited repository revision rather than a moving branch. Official release metadata was checked read-only.

Twelve feature records cover Branching, Concentric Rings, Drag + Shift, Invoke, context-aware menus, read-only text previews, Quick Convert, Advanced Convert, background Jobs, executable custom actions, Control Center and appearance/configuration. Default terminal, SHA-256 and executable examples are explicitly logging-only. External custom programs must be installed; argv and whole-placeholder restrictions are disclosed. No synthetic screenshot or W3 simulation was introduced.

Compatibility separates implemented capability, environment verification and published package availability. Mint 22.3/Cinnamon/Nemo/X11/amd64 is the primary owner-tested setup, qualified as RC testing followed by stable publication approval—not exhaustive stable desktop certification. Ubuntu 24.04 container package installation is distinguished from an unverified desktop. Debian-based and other X11 setups remain unverified where evidence is missing. Non-composited fallback, conditional XWayland Invoke, unavailable Wayland drag, unsupported native Wayland wheel, distribution packages, CPU targets, mixed-DPI/monitor gaps and feature dependencies are explicit. Missing coverage is never presented as proof of incompatibility.

Shared strict schemas validate features, evidence, compatibility, roadmap, release/history, media and guide frontmatter. Cross-checks reject unknown evidence, unpinned repository sources, manual claims without named environments/reports, unsupported native Wayland claims, unpublished shipped versions, future roadmap commitments, invalid asset identity/checksums, absent-feature release claims, stale guides and unversioned native media. Builds check media hashes and source paths. No runtime API, framework, CMS or backend was added.

## Limitations and next handoff

Current v0.3.0 native desktop captures remain outstanding. Historical Control Center media includes v0.1.1; N3 imagery is sandbox/renderer evidence. None is presented as current desktop UI. The [media audit and exact capture checklist](../website/W2-media.md) covers Branching/text preview, Concentric/image conversion, Advanced Convert, Jobs and Control Center in appropriate themes, with provenance and privacy review.

No live Mint desktop, alternate file manager, Wayland compositor, non-composited session, mixed-DPI/hotplug environment or physical mobile device was exercised by W2. N5 manual gaps remain explicit. Chromium automation does not replace Firefox/Safari, assistive-technology or owner desktop testing; these were not completed here. The source-build instructions were audited, but a fresh packaged source installation across distributions was not repeated. Release data is intentionally static and needs a future human-reviewed update. Existing historical source/security-policy wording is qualified rather than changed outside scope.

W2 is ready to serve as the content/evidence foundation for W3 after explicit authorization. Before claiming real-application parity for a browser simulation, verify its geometry, navigation, states and copy against the current native app, and collect the owner media above. W2 completion does not authorize W3, W4, deployment or publication.
