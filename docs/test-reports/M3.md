## 3. Reconciliation of `AC-3.7` / `AC-3.8` Input Pass-Through Policy (`AGENTS.md` §2.4, `ADR-0001`)

As discovered empirically in M0 Spike [`S-6`](file:///home/marwanmohamed/Documents/work/rust/radivine/docs/spikes/S-6.md) and codified in `AGENTS.md` §2.4, `ADR-0001`, and `FEASIBILITY_STUDY.md` §10:

1. **Why `input.passthrough = false` is the Mandatory Safe Default:**
   - In GTK3 / Nemo (`gdkdnd-x11.c`), holding `Shift` during a drag forces the suggested drag action to `GDK_ACTION_MOVE`.
   - If the X11 `SHAPE` input mask is cut tightly around the wheel (`input.passthrough = true`) and the user releases the mouse button outside the wheel while still holding `Shift` over a Nemo folder, the drop bypasses Radivine and lands directly on the underlying Nemo folder as a **native file Move**, moving the user's files instead of cancelling the radial menu.
   - Therefore, `input.passthrough` defaults to `false`: while a drag-mode wheel session is active, the full-monitor overlay captures pointer release events outside the wheel cluster, replies `XdndStatus(accept = 0)` / `XdndFinished(accept = 0)`, cancels the drag cleanly (GTK3 snaps the drag icon back), and unmaps the overlay.
   - To continue a native Nemo drag after opening the wheel, the user presses `Shift` a second time (`toggle_off_on_repress = true`), which unmaps the overlay and nudges the pointer (`0-px WarpPointer`) so Nemo retargets the underlying window.
2. **Opt-In `input.passthrough = true` Also Implemented & Verified:**
   - When a user explicitly sets `input.passthrough = true` in `config.toml`, `SessionController::sync_input_region` applies the scanline-rasterized `XShapeCombineRectangles` mask for all open wheel discs (`r_out + hit_margin`) and navigation corridors.
   - Moving the pointer outside the shaped cluster delivers `XdndLeave` with `drag_ended = false`, transitioning `SessionController` to `SessionState::LeftGrace` and dismissing the wheel to `SessionState::Armed` after `wheel.leave_grace_ms` (`350 ms` default, `120 ms` in test suite) while the underlying drag continues uninterrupted.
   - Both modes are tested in `apps/radivine/tests/m3_drag_acceptance.rs`.

## 5. Manual Nemo Testing Instructions

To manually test Radivine's real desktop drag-and-drop integration with Nemo:

1. **Build and start the Radivine daemon in a terminal:**
   ```bash
   cargo build --release -p radivine
   RUST_LOG=info ./target/release/radivine daemon
   ```
   *(Optional: prefix with `RADIVINE_DEBUG_OVERLAY=1` to visualize the hit-test zones, navigation corridors, and intent triangles.)*
2. **Create disposable test files and open Nemo:**
   ```bash
   mkdir -p /tmp/radivine-manual-test
   echo "hello radivine" > /tmp/radivine-manual-test/sample.txt
   echo "second file" > "/tmp/radivine-manual-test/notes with spaces.txt"
   nemo /tmp/radivine-manual-test &
   ```
3. **Test Drag + Shift Activation & Nested Wheel Selection:**
   - Select one or both files in Nemo and begin dragging with the **left mouse button held down**.
   - While holding the left mouse button, press **`Shift`** once.
   - The Radivine wheel appears centered at the cursor (with a `2` badge on the center hub if two files are dragged).
   - While still holding the left mouse button, move upward onto **File Preview** (`[0]`) — the child wheel (**Full Preview**, **Head**, **Tail**) opens above it.
   - Move into **Head** (`[0, 1]`) and **release the left mouse button**.
   - Observe in the daemon terminal log:
     `committed radial wheel action action_id=radivine.preview.head path=[0, 1] mode="Drag" source_app=Some("nemo") uris=[...]`
   - Verify that the files in `/tmp/radivine-manual-test` remain completely untouched.
4. **Test Cancellation & Second-Shift Toggle-Off:**
   - Start dragging a file in Nemo, press **`Shift`** to summon the wheel, and immediately release the mouse button on the center hub without moving — the wheel closes cleanly with no action dispatched.
   - Start dragging a file in Nemo, press **`Shift`** to summon the wheel, then press **`Shift` a second time** while still holding the mouse button — the wheel hides and your normal Nemo drag continues.
5. **Inspect daemon status or stop the daemon:**
   ```bash
   ./target/release/radivine status --json
   ./target/release/radivine quit
   ```
