## 1. Summary of C5 Implementation, Defect Fixes & Optimizations

### 1.1 Cooperative Mid-Create Staging Cleanup Fix (`035d23c`)
- **Defect Identified by C5 Soak Harness:** During the initial development run of `c5_soak_test`, cancelling a batch while an item worker was inside [`PendingOutput::create`](../../crates/radivine-convert/src/output.rs) right after `mkdirat` (`.rvstage-<uid>`) and `openat` (`.part`) had created the staging artifacts on disk caused `check_cancel(control)` to return `Err(ConversionError::Cancelled)` before constructing `PendingOutput`, leaving the `.part` file and `.rvstage-<uid>` directory on disk.
- **Fix:** Updated [`PendingOutput::create`](../../crates/radivine-convert/src/output.rs) to clean up the newly created `.part` file (`unlinkat`) and empty `.rvstage-<uid>` directory (`unlinkat(..., AT_REMOVEDIR)`) before returning `Err(ConversionError::Cancelled)`, and updated [`WorkerItemControl::check_cancelled`](../../apps/radivine-worker/src/fence.rs) to clean up any empty stage directory if cancelled prior to `.part` registration. Added unit regression test `pending_output_create_cancellation_cleans_up_stage_and_part`.

### 1.2 Codec Performance & Memory Optimizations (`c7119f5`)
- **SIMD Acceleration:** Enabled `sse41` and `avx2` features on `libwebp-sys 0.14.4` and `simd` on `jpeg-encoder 0.7.1` in [`Cargo.toml`](../../Cargo.toml).
- **Multi-Threaded Lossy WebP Encoding:** Set `webp_cfg.thread_level = 1` in [`ffi/radivine-webp/src/lib.rs`](../../ffi/radivine-webp/src/lib.rs).
- **Zero-Copy Lossy WebP Output Path:** Eliminated an extra full-output buffer clone in [`ImageBackend::encode_webp_lossy`](../../crates/radivine-convert-image/src/lib.rs) when no ICC or EXIF RIFF chunk muxing is needed.
- **Photographic Corpus Synthesis:** Updated [`generate_photo_rgb`](../../tools/convert-corpus/src/lib.rs) to synthesize spatially correlated photographic gradients, macro blocks, and fine sensor grain rather than incompressible white noise.
- **Measured Speedup:** `12 MP JPEG -> WebP q80 m4` improved from `1,161.2 ms` (C1 baseline) to **`568.3 ms`** (`2.04×` faster), and `12 MP PNG -> JPEG q82` improved from `230.7 ms` to **`150.2 ms`** (`1.54×` faster).

### 1.3 Systemd Worker Hardening & Supply-Chain Remediation (`f0d9ac0`)
- **`Q-B` Systemd Sandboxing Verification:** Tested [`packaging/radivine-worker.service`](../../packaging/radivine-worker.service) on the live Linux Mint 22.3 `systemd --user` instance (`systemd-run --user --wait`). Discovered that `/run/media` does not exist on Ubuntu 24.04 / Linux Mint 22.3 by default, causing `ReadWritePaths=%h %t /tmp /media /mnt /run/media` (without `-` prefixes) to fail unit startup with `Invalid ReadWritePaths`. Fixed by prefixing optional mount points with `-` (`ReadWritePaths=%h %t /tmp -/media -/mnt -/run/media`) and adding `ProtectControlGroups=yes`, `RestrictSUIDSGID=yes`, and `LockPersonality=yes`. Verified with both `systemd-run --user` (`Finished with result: success`) and `systemd-analyze --user verify`.
- **Supply-Chain & License Policy (`deny.toml` & `Cargo.lock`):** Updated transitive `clipboard-win` (`5.4.1 -> 5.4.3`) in `Cargo.lock` to clear a yanked version warning, and added `Unicode-3.0` (`icu_*`) and `CDLA-Permissive-2.0` (`webpki-root-certs`) to [`deny.toml`](../../deny.toml). Verified both `cargo audit` (`0` vulnerabilities across 496 crates) and `cargo deny check` (`advisories ok, bans ok, licenses ok, sources ok`).

### 1.4 CI Dependency-Graph Enforcement & Debian Packaging (`9529af2`, `2af83d2`)
- Created [`scripts/check-dep-graph.sh`](../../scripts/check-dep-graph.sh) (`X7`) enforcing crate dependency invariants via `cargo metadata` and `cargo tree` (`radivine` and `radivine-control` never link `rusqlite`, `libwebp-sys`, or `radivine-worker`; `radivine-worker` never links `radivine-wheel`, `radivine-render`, `x11rb`, or `eframe`).

Because C5 authorization strictly prohibits modifying the owner's installed `v0.1.1` package or restarting live desktop services during automated preparation, execute the following checklist on your Linux Mint 22.3 Cinnamon X11 desktop before approving the final `v0.2.0` release:

### 9.1 Safe Upgrade to `radivine_0.2.0_amd64.deb` (Switch from Dev Mode to Installed RC)
```bash
# 1. Stop the workspace development daemon/worker and restore the system Nemo action:
./scripts/dev/dev-stop.sh --all

# 2. Verify the release candidate checksum:
(cd target/debian && sha256sum -c SHA256SUMS.txt)

# 3. Install the v0.2.0 release candidate package over v0.1.1:
sudo apt install ./target/debian/radivine_0.2.0_amd64.deb

# 4. Reload systemd user units and restart the background wheel daemon:
systemctl --user daemon-reload
systemctl --user restart radivine.service
systemctl --user status radivine.service
```

### 9.2 Interactive Desktop Verification Checklist (Linux Mint Cinnamon X11)
- [ ] **1. Existing Config & Custom Actions Preservation:** Run `radivine-control` and confirm your existing `Wheel`, `General`, and `Custom Actions` settings from `v0.1.1` are intact.
- [ ] **2. Nemo `Drag + Shift` Quick Convert:** Drag a `.png` file in Nemo, press `Shift`, navigate to **`Convert ▸ Image ▸ WebP`**, and release. Confirm the wheel closes immediately, a desktop notification appears, and `<stem>.webp` is created beside the original without modifying the source `.png`.
- [ ] **3. Nemo Right-Click `Open in Radivine` & Advanced Convert:** Right-click 2–3 images in Nemo (including filenames with spaces or Arabic characters), choose **Open in Radivine**, and select **`Convert ▸ Image ▸ Advanced…`**. Adjust target format/quality/suffix and click **Convert**, then click **Open Jobs**.
- [ ] **4. Control Center `Jobs` Page:** Verify live/completed job progress, click **Open folder** on a converted item (Nemo highlights the output file), and test **Retry** or **Clear history**.
- [ ] **5. Control Center `Conversion` Page:** Change a Quick Convert preset or output suffix in **Conversion**, click **Save Changes**, and confirm the next Quick Convert uses the new setting immediately.
- [ ] **6. Clipboard & Arabic Text Input:** Copy text (`Ctrl+C`) from a browser/terminal (including Arabic text such as `تحويل الصور`) and paste (`Ctrl+V`) into a text field in **Custom Actions** or **Advanced Convert**. Confirm native paste and shaped Arabic glyph rendering.
- [ ] **7. Logout/Login Autostart & Worker Idle Exit:** Wait 60 seconds after a conversion job and confirm `pgrep -a radivine-worker` is empty (`0` processes when idle), while `radivine.service` remains active across logout/login.

### 9.3 Safe Rollback to `v0.1.1` (If Needed)
```bash
sudo apt install --allow-downgrades ./target/debian/radivine_0.1.1_amd64.deb
systemctl --user daemon-reload
systemctl --user restart radivine.service
```
