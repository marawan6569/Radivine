## 1. Implemented Geometry and Navigation Behavior

### 1.1 Concentric Geometry & Preflight (`crates/radivine-wheel/src/concentric.rs`, `§I1`–`§I2`)
- **Fixed Shared Center (`C`):** Root and all child rings `L = 0 .. D_max - 1` share one immutable center `C` per session. No pointer warping, dynamic recentering, or mid-session layout switching.
- **Annular Radii (`§I1.3`):**
  - Root ring (`L = 0`): `R_in(0) = config.root_inner_radius` (`40.0 lp` app default, `38.0 lp` engine default), `R_out(0) = config.root_outer_radius` (`128.0 lp` app default, `116.0 lp` engine default).
  - Child rings (`L >= 1`): thickness `W_ring = 60.0 lp`, inter-ring neutral gap `G_ring = 6.0 lp`:
    - `R_in(L) = R_out(0) + L * 6.0 + (L - 1) * 60.0`
    - `R_out(L) = R_in(L) + 60.0`
    - `R_mid(L) = 0.5 * (R_in(L) + R_out(L))`
    - `R_max(D) = R_out(D - 1)` (with `R_out(0) = 128 lp`: `D=1 -> 128 lp`, `D=2 -> 194 lp`, `D=3 -> 260 lp`, `D=4 -> 326 lp`, `D=6 -> 458 lp`).
- **Equal Full-Circle Sectors (`§I1.4`):**
  - Every ring partitions the full `2π` circle into `N` equal sectors starting at top (`-π/2`) and ordered clockwise (`Δθ(N) = 2π / N`).
  - `N = 1` occupies the full `[0, 2π)` annulus with no angular separator (`δ(L, 1) = 0`).
  - `N >= 2` reserves a physical `2.0 lp` separator gap (`δ(L, N) = (2.0 / R_mid(L)) / 2 = 1.0 / R_mid(L)` radians half-angle).
  - Child ring orientation is fixed at top (`-π/2`) and independent of the parent sector angle.
- **Minimum Target-Core Validation (`§I1.5`):**
  - Validates `W_eff(L) >= 32.0 lp` and `S_core(L, N) >= 32.0 lp` for all `L in 0 .. D_max - 1` and `N in 1 ..= max_segments_per_ring`, plus positive finite radii (`R_out(0) - R_in(0) >= 34.0 lp`, `R_in(0) >= 24.0 lp`). Invalid configurations fall back deterministically with `LayoutFallback::TargetTooSmall`.
- **Whole-Cluster Preflight & Caption Reservation (`§I2`):**
  - Evaluates full configured `max_depth` (`D_max`) before session mapping, reserving `M_edge = 16.0 lp`, `M_outer = 16.0 lp`, `G_cap = 14.0 lp`, `H_cap = 54.0 lp`, `W_cap = 260.0 lp`, and `R_cap = max(R_max, 130.0)`.
  - Requires `W_vp >= 2 * R_cap + 32.0` and `H_vp >= 2 * R_max + 100.0`; prefers below-cluster caption placement and switches to above-cluster placement only when below placement cannot fit.
  - Returns `Err(LayoutFallback::InsufficientSpace)` when neither placement fits, shifting `C` once before show and activating the displaced-center approach guard whenever `||C - P_0|| > R_in(0) * 0.5`.
  - Uses identical preflight parameters for the initial 1-segment placeholder and the installed `MenuTree` (`set_menu` / `set_menu_at_pointer`), guaranteeing zero center shift or fallback oscillation when the real menu arrives.
- **Sector Content Boxes (`§I8.4`):**
  - Computes deterministic `ConcentricContentBox` for each sector (`44×40 lp` stacked icon+label for `N <= 8`, `28×28 lp` icon-only for `N >= 9`, `72×24 lp` single-segment pill for `N == 1` centered at `(cx, cy - R_mid(0))`).

### 1.2 Strict Annular Hit Testing & Hover Hysteresis (`crates/radivine-wheel/src/concentric.rs`, `§I3`–`§I4`)
- **Dedicated `NestedHit` Classification (`hit_concentric`):**
  - Never reuses the Branching deepest-wheel-first hub loop.
  - Classifies any point relative to `C` and open depth `D_open` into:
    - `Approaching { distance, release_radius }` while the displaced-center approach guard is active (`d > R_slop(C)`).
    - `CentralHub { distance }` for `d < R_in(0) - ε_r` (`ε_r = 0.5 lp`).
    - `RadialBoundary { ring, inner_edge }` within `±0.5 lp` of `R_in(L)` or `R_out(L)`.
    - `RadialGap { inner_ring, outer_ring }` strictly between `R_out(L) + ε_r` and `R_in(L + 1) - ε_r`.
    - `AngularSeparator { ring, between }` within `±δ(L, N)` of a sector boundary (for `N >= 2`), including across the `-π/2` top wrap seam.
    - `Sector { ring, sector_index, path, enabled, is_submenu, in_outward_band }` inside an open ring's active sector span (with outward band `r >= R_out(L) - 0.30 * (R_out(L) - R_in(L))`).
    - `OuterMargin { distance }` for `R_out(D_open - 1) + ε_r < d <= R_out(D_open - 1) + 16.0`.
    - `Outside { distance }` for `d > R_out(D_open - 1) + 16.0`.
- **Visual Hysteresis Separation (`retain_hover_hysteresis`):**
  - Retains the previous visual hover highlight across up to `3.0 lp` into an adjacent radial boundary/gap or `config.hysteresis_angle_deg` (`3.5°` app default, `4.0°` engine default) into an angular separator on the same ring, while keeping strict action eligibility (`drop_target() == None`) false in all neutral zones.

### 1.3 Concentric Hierarchy Navigation & Safe Activation (`crates/radivine-wheel/src/concentric_nav.rs`, `§I5`–`§I7`)
- **Single Open Child Per Ring & Persistent Ancestor Path (`§I5.1`–`§I5.3`):**
  - Deepest open ring `D_open - 1` opens a submenu after `submenu_dwell_ms` (`110 ms` app default, `140 ms` engine default), immediately on entering its outer `30%` radial band (when `submenu_open_in_outer_band` is enabled), or on Invoke click/Enter/Right.
  - Opening a deeper ring preserves all ancestor rings `0 .. L` at full opacity (`1.0`) with active breadcrumb state.
- **Ancestor Sibling Replacement, Grace Deadlines & Two-Sample Outward Shortcut (`§I5.4`–`§I5.5`):**
  - Hovering a sibling sector on an ancestor ring `L < D_open - 1` sets `pending_sibling` with deadline `now + submenu_dwell_ms` (`110 ms`) while keeping deeper rings `L + 1 .. D_open - 1` alive during diagonal crossings.
  - Two consecutive pointer samples on the ancestor sibling with `Δr >= +2.0 lp` and the second sample inside the outer `30%` band adopt the sibling immediately without waiting for the timer.
  - Returning to a deeper ring `> L` or entering a radial gap cancels `pending_sibling` so stale timers cannot fire.
- **Inward Return & Central Hub Dwell Collapse (`§I5.6`–`§I5.7`):**
  - Moving inward onto an already-selected ancestor sector `S(L, k_open(L))` updates hover/caption to that ancestor while keeping deeper rings open.
  - Dwelling inside `CentralHub` for `hub_close_delay_ms` (`180 ms` app default, `300 ms` engine default) collapses all child rings `L >= 1` while keeping root open.
- **Fresh-Motion Exposure Guard & Single-Transition Per Input (`§I4.4`, `§I5.8`):**
  - Newly opened/replaced rings start with `armed_after_motion = false` (`exposed_at_pointer = Some(P)`), blocking hover/dwell/band/release eligibility on that ring until a real pointer move satisfies `||P' - P|| >= 4.0 lp` inside the ring's annulus or keyboard navigation explicitly enters the ring.
  - At most one structural hierarchy transition occurs per `handle` or `tick` call.
- **Invoke Click/Release, Keyboard Navigation & Pointer Takeover (`§I6`):**
  - Supports `Left`/`Right`/`Up`/`Down`/`Tab`/`Shift+Tab`/`Enter`/`Space`/`Back`/`Escape` across rings, skipping disabled items when enabled siblings exist, and requiring `>= 6.0 lp` real pointer motion to reclaim selection from keyboard navigation.
  - Enforces generation-matched press/release (`ConcentricPress { path, ring, sector_index, tree_generation }`) so releasing after a submenu switch or on a different sector never commits.
- **Live Enablement & Session Suspension (`§I7`):**
  - `set_enabled` / `set_enabled_at` updates node enablement and `disabled_reason` in place without resetting open rings or geometry, immediately invalidating `drop_target` and disarming pending presses if the target or any ancestor becomes disabled.
  - `suspend_interaction` disarms all eligibility, timers, and presses while preserving the visible ring geometry for clean dismissal.

## 7. Known Limitations and N3 Prerequisites

1. **Intermediate Scene Representation in N2:** `WheelSession::rebuild_concentric_scene` emits deterministic per-ring `WheelVisual` and `CaptionVisual` data using the existing M1b scene structs so engine tests can inspect ring centers, radii, segment spans, opacities, and captions. Milestone N3 will extend `radivine-wheel::scene` and `radivine-render` with explicit Concentric annular ring rendering (no child hubs, no child drop shadows, supplied `ConcentricContentBox` placement, `›`-joined path breadcrumb caption, and active parent-to-child boundary arc guide) and incremental damage tracking (`T-REN1`–`T-REN7`).
2. **Production Desktop Safety Guard Active:** `apps/radivine/src/session.rs` intentionally overrides `WheelLayout::Concentric` to `WheelLayout::Branching` during N2 so manually editing `config.toml` cannot trigger unimplemented Concentric desktop rendering before N3 and N4 are complete.
