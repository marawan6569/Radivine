## 1. Implemented Geometry and Navigation Behavior

### 1.1 Concentric Geometry & Preflight (`crates/radivine-wheel/src/concentric.rs`, `§I1`–`§I2`)
- **Fixed Shared Center (`C`):** Root and all child rings `L = 0 .. D_max - 1` share one immutable center `C` per session. No pointer warping, dynamic recentering, or mid-session layout switching.
- **Annular Radii (`§I1`):**
  - Root ring (`L = 0`): `R_in(0) = cfg.radius_root[0]` (`40.0 lp` app default, `38.0 lp` engine default), `R_out(0) = cfg.radius_root[1]` (`128.0 lp` app default, `116.0 lp` engine default).
  - Child rings (`L >= 1`): thickness `CONCENTRIC_RING_THICKNESS = 60.0 lp`, inter-ring neutral gap `CONCENTRIC_RING_GAP = 6.0 lp`:
    - `R_in(L) = R_out(0) + 6.0 * L + 60.0 * (L - 1)`
    - `R_out(L) = R_in(L) + 60.0`
    - `R_reserve(D) = R_out(D - 1)` (with shipped app root `40 / 128`: `D=1 -> 128 lp`, `D=2 -> 194 lp`, `D=3 -> 260 lp`, `D=4 -> 326 lp`, `D=6 -> 458 lp`).
- **Equal Full-Circle Sectors (`§I1`):**
  - Every ring partitions the full `2π` circle into `n` equal sectors starting at top (`3π/2`, `0` East, clockwise `+y` down: `Δ = 2π / n`, `center_k = normalize_angle(3π/2 + k * Δ)`).
  - `n = 0` (initial placeholder before `set_menu` / `set_menu_at_pointer`): empty spans and content boxes, zero separator half-angle, no selectable targets.
  - `n = 1`: occupies the full `[0, 2π)` annulus with no angular separator (`δ = 0`).
  - `n >= 2`: reserves a constant `CONCENTRIC_SEPARATOR_WIDTH = 2.5 lp` arc separator at the ring's inner boundary (`δ = asin(min(1, 2.5 / (2 * R_in(L))))`), giving usable angular span `[a0_k + δ, a1_k - δ]`.
  - Child ring orientation is fixed at top (`3π/2`) and independent of the parent sector angle.
- **Minimum Target-Core Validation (`§I1`, `§I2`):**
  - Requires finite root radii with `20.0 <= R_in(0) <= 200.0`, `R_out(0) <= 240.0`, and root thickness `R_out(0) - R_in(0) >= 60.0 lp`.
  - Validates `target_core_fits_ring(R_in(L), R_out(L), n)` across every ring `L in 0 .. D_max - 1` and item count `n in 1 ..= max_items_per_wheel`: checks that the exact `32.0 × 32.0 lp` radial/tangential target rectangle (`u in [r_c - 16, r_c + 16]`, `v in [-16, +16]` around `r_c = R_in(L) + 0.55 * (R_out(L) - R_in(L))`, including all 4 corners and radial midpoints) lies strictly inside `(R_in(L) + 1e-4, R_out(L) - 1e-4)` and `|atan2(v, u)| < Δ/2 - δ - 1e-5`. Invalid configs fail preflight with `Err(LayoutFallback::TargetTooSmall)`.
- **Whole-Cluster Preflight & Caption Reservation (`§I2`):**
  - Evaluates full configured `max_depth` (`D_max`) before session mapping, reserving `CONCENTRIC_EDGE_PAD = 8.0 lp` (`E = 8 lp`), `CONCENTRIC_CAPTION_W = 280.0 lp`, `CONCENTRIC_CAPTION_H = 64.0 lp`, and `CONCENTRIC_CAPTION_GAP = 10.0 lp` (`G_cap = 10 lp`) below `R_reserve`.
  - Requires `W_min = max(2 * R_reserve, 280.0) + 16.0` and `H_min = 2 * R_reserve + 10.0 + 64.0 + 16.0` (for shipped app root `40 / 128`: `D=1 -> 296×346`, `D=2 -> 404×478`, `D=3 -> 536×610`, `D=4 -> 668×742`, `D=6 -> 932×1006`).
  - Clamps `C.x` into `[vp.x + max(R_reserve, 140) + 8, vp.right() - max(R_reserve, 140) - 8]` and `C.y` into `[vp.y + R_reserve + 8, vp.bottom() - R_reserve - 74 - 8]`, placing the caption strictly below the reserved outer ring at `y = C.y + R_reserve + 10.0`.
  - Activates the displaced-center approach guard (`plan.approach_required = true`) whenever `anchor.distance(C) > 0.5 lp` (`CONCENTRIC_APPROACH_EPS = 0.5 lp`).
  - Uses identical preflight parameters for `menu = None` placeholder sessions and installed `MenuTree` sessions (`set_menu` / `set_menu_at_pointer`), guaranteeing zero center shift or fallback oscillation when the real menu arrives.
- **Sector Content Boxes (`§I8`):**
  - Computes deterministic `SectorContentBox { rect, mode }` (`compute_sector_content` / `sector_box_fits`) centered at `P_c = C + r_c * (cos θ_c, sin θ_c)` where `r_c = R_in + 0.55 * (R_out - R_in)`:
    - Binary-searches integer width `w in 24 ..= 128 lp` at `h = 37.0 lp` (`20 lp` icon + `3 lp` gap + `14 lp` label) with `4.0 lp` radial/angular clearance (`sector_box_fits`); selects `ContentMode::IconAndLabel` when `max_w >= 48.0 lp`.
    - Falls back to `ContentMode::IconOnly` (`20 × 20 lp`) when `max_w < 48.0 lp` and `has_icon == true`, or binary-searches `w in 24 ..= 128 lp` at `h = 14.0 lp` for `ContentMode::LabelOnly` when `has_icon == false`.

### 1.2 Strict Annular Hit Testing & Hover Hysteresis (`crates/radivine-wheel/src/concentric.rs`, `§I3`–`§I4`)
- **Dedicated `NestedHit` Classification (`hit_concentric`):**
  - Never reuses the Branching deepest-wheel-first hub loop; hub distance `d < h - ε_r` is tested once against `C`.
  - Precedence and exact zones (`CONCENTRIC_RADIAL_EPS = 1e-4 lp`, `CONCENTRIC_ANGULAR_EPS = 1e-5 rad`):
    1. `NestedHit::Approach` whenever `plan.approach_required` is `true` (`Approach` guard wins first).
    2. `NestedHit::Hub` when `d < R_in(0) - 1e-4`.
    3. `NestedHit::RadialBoundary { level }` when `|d - R_in(level)| <= 1e-4` or `|d - R_out(level)| <= 1e-4` on any open ring.
    4. `NestedHit::Item { level, index }` vs `NestedHit::Separator { level }` when `R_in(level) + 1e-4 < d < R_out(level) - 1e-4`:
       - `n == 0` (placeholder): returns `NestedHit::Separator { level }`.
       - `n == 1`: returns `NestedHit::Item { level, index: 0 }` at all angles (no separator seam).
       - `n >= 2`: returns `NestedHit::Item { level, index }` when strictly inside `[a0 + δ + 1e-5, a1 - δ - 1e-5]`, else `NestedHit::Separator { level }`.
    5. `NestedHit::RadialGap { inner_level }` when `R_out(level) + 1e-4 < d < R_in(level + 1) - 1e-4` between two open rings.
    6. `NestedHit::OuterMargin` when `R_out(last_open) + 1e-4 < d <= R_out(last_open) + cfg.hit_margin` (`12.0 lp`).
    7. `NestedHit::Outside` when `d > R_out(last_open) + cfg.hit_margin` (including unused reserved capacity for unopened deeper rings).
- **Visual Hysteresis Separation (`retain_hover_hysteresis`):**
  - Retains the previous visual hover highlight `(level, index)` only when:
    - `strict_hit == NestedHit::Separator { level }` on the same ring and the angular distance beyond the usable sector edge is `<= min(cfg.hysteresis_deg, Δ_deg * 0.15)` (`3.5°` app default), or
    - `strict_hit == NestedHit::RadialGap { inner_level: level }` or `NestedHit::RadialBoundary { level }` within `< 3.0 lp` (`CONCENTRIC_RADIAL_HYSTERESIS_MAX`) of `R_out(level)` while remaining within the sector's usable angular span.
  - Visual hover retention never makes a non-`Item` hit executable (`drop_target()` always uses strict hit eligibility).

### 1.3 Concentric Hierarchy Navigation & Safe Activation (`crates/radivine-wheel/src/concentric_nav.rs`, `crates/radivine-wheel/src/session.rs`, `§I5`–`§I7`)
- **Single Open Child Per Ring & Persistent Ancestor Path (`§I5`):**
  - Deepest open ring opens a submenu after `cfg.dwell_ms` (`110 ms` app default, `140 ms` engine default), immediately on a subsequent pointer sample on that sector inside the outer band `d >= R_in(L) + cfg.band * (R_out(L) - R_in(L))` (`cfg.band = 0.65`, i.e., `97.2 lp` on root `40..128`) with outward radial progress `d_now - d_prev >= 2.0 lp`, or on Invoke click / keyboard `Activate` / `Digit`.
  - Simply entering a sector inside the outer band on the first sample starts the dwell timer without opening immediately; a subsequent `>= 2.0 lp` outward move on that sector opens via band.
  - Opening a deeper ring preserves all ancestor rings `0 .. L` with `WheelRole::Ancestor`, target opacity `0.72` (vs `WheelRole::Active` opacity `1.0`), `scale = 1.0`, `pop = 0.0`, and `seg.on_path = true` on each open parent sector.
- **Ancestor Sibling Replacement, Grace Deadlines & Two-Sample Outward Shortcut (`§I5`):**
  - Hovering a sibling sector on an ancestor ring `L < deepest` while deeper rings `> L` are open records `PendingSibling { level: L, index, path, entered_at: t0, deadline: t0 + cfg.grace_ms, samples: 1, last_radius }` (`cfg.grace_ms = 180 ms` app default, `300 ms` engine default) without immediately closing deeper rings.
  - While `PendingSibling` is active before `t0 + grace_ms`, `drop_target()` returns `DropTarget::Reject`.
  - Jitter or repeated samples on the same pending sibling never extend `deadline`.
  - If the pointer remains on the pending sibling at `t >= t0 + grace_ms`, `tick` adopts the sibling, closes rings `> L`, and if the sibling is a submenu schedules its child ring for `max(t0 + dwell_ms, t0 + grace_ms)`.
  - Two-sample outward shortcut: if a second pointer sample on the same pending submenu sibling satisfies `samples >= 2`, `d_now - last_radius >= 2.0 lp`, and `d_now >= R_in(L) + 0.65 * (R_out(L) - R_in(L))` (when band opening is enabled), the sibling is adopted and its child ring opens immediately before `grace_ms`.
  - Re-entering any existing deeper ring `> L` before `t0 + grace_ms` cancels `PendingSibling` and retains the deeper chain.
- **Inward Return & Central Hub Dwell Collapse (`§I5`):**
  - Moving inward onto an open-parent sector on ring `L < deepest` cancels `PendingSibling` and keeps all deeper rings open.
  - Dwelling inside `NestedHit::Hub` (`d < R_in(0) - 1e-4`) arms `ConcentricHubCloseTimer` for `now + cfg.hub_close_ms` (`150 ms` default); if the pointer stays in the hub through `now + 150 ms`, all child rings `L >= 1` collapse while root stays open.
- **Displaced-Center Approach Guard, Fresh-Motion Exposure Guard & Single Transition Per Input (`§I2`, `§I4`, `§I5`):**
  - When `anchor.distance(C) > 0.5 lp`, `approach_required` starts `true` (`NestedHit::Approach`) and clears only when a real pointer motion sample (past `activation_slop`) enters the hub interior `d < R_in(0) - 1e-4`.
  - Whenever root menu content is installed via `set_menu_at_pointer` or a child ring `L` is opened/replaced, `exposure_guards[L] = Some(pointer)` blocks hover, dwell, band opening, and drop/press eligibility on ring `L` until a subsequent pointer sample inside ring `L`'s annulus satisfies `p.distance(guard_pt) >= 2.0 lp` (`CONCENTRIC_FRESH_MOTION_LP = 2.0 lp`).
  - At most one structural hierarchy transition occurs per `handle` or `tick` call.
- **Invoke Click/Release, Keyboard Navigation & Pointer Takeover (`§I6`):**
  - Supports `NavKey::{Next, Prev, Activate, Back, Cancel, Digit(1..=9)}` on the deepest open ring without requiring pointer slop or hub visit.
  - `Next` and `Prev` cycle through **all** items `0 .. n - 1` on the deepest open ring **including disabled items** so disabled items can be focused to read their `disabled_reason` in the caption; `Activate` and `Digit` check `menu_path_and_ancestors_enabled` and refuse to open or commit any item that is disabled or has a disabled ancestor.
  - Switching from keyboard navigation back to pointer control requires `p.distance(takeover_point) >= 2.0 lp` (`CONCENTRIC_FRESH_MOTION_LP = 2.0 lp`) of real pointer motion.
  - Enforces generation-matched press/release (`ConcentricPress { path, generation }`) and supports both `InvokeSelect::Click` (direct click on leaf or hub-marking press in hub + drag + release on leaf) and `InvokeSelect::Release`.
- **Live Enablement & Session Suspension (`§I7`):**
  - `set_enabled` / `set_enabled_at` updates node enablement and `disabled_reason` in place without altering ring geometry or closing open rings, immediately updating `drop_target()`, caption disabled state, and disarming any invalidated pending press.
  - `suspend_interaction` irreversibly disarms all eligibility, timers, and presses while preserving visible geometry for dismissal.

## 8. Known Limitations and N3 Prerequisites

1. **Intermediate Scene Representation in N2:** `WheelSession::rebuild_concentric_scene` emits deterministic per-ring `WheelVisual` (with `WheelRole::Ancestor` at `0.72` target opacity vs `WheelRole::Active` at `1.0` target opacity, `scale = 1.0`, `pop = 0.0`, `on_path` markers) and `CaptionVisual` data using the existing scene structs, while `ConcentricRingGeometry` supplies the exact binary-searched `SectorContentBox` (`ContentMode::{IconAndLabel, IconOnly, LabelOnly}`) and `separator_half_angle` for every sector. Milestone N3 will wire `radivine-wheel::scene` and `radivine-render` with explicit Concentric annular ring rendering (no child hubs, no child drop shadows, supplied `SectorContentBox` placement, `›`-joined path breadcrumb caption, and active parent-to-child boundary arc guide) and incremental damage tracking (`T-REN1`–`T-REN7`).
2. **Production Desktop Safety Guard Active:** `apps/radivine/src/session.rs` intentionally overrides `WheelLayout::Concentric` to `WheelLayout::Branching` during N2 so manually editing `config.toml` cannot trigger unimplemented Concentric desktop rendering before N3 and N4 are complete.
