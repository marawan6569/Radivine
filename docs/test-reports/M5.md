## 1. Summary of Implemented M5 Components

1. **Standalone Preview Application (`apps/radivine-viewer`):**
   - Built as a completely separate process (`#![forbid(unsafe_code)]`, zero dependencies on any `radivine-*` crate per `ARCHITECTURE.md` §2.2) using `eframe` / `egui` `0.37`.
   - CLI contract (`ACTION_SYSTEM.md` §8.1):
     `radivine-viewer --mode <full|head|tail> [--lines N] [--title TITLE] [--theme <dark|light|auto>] [--print] -- <PATH>`
     - Exit `0`: normal close
     - Exit `2`: CLI usage error (e.g., `--lines 0`)
     - Exit `3`: cannot open file (missing, broken symlink, permission denied, directory, special file, or binary file)
   - Polished desktop UI (`apps/radivine-viewer/src/ui.rs`):
     - Top header bar with mode badge (`FULL PREVIEW`, `HEAD - N LINES`, `TAIL - N LINES`), filename + full-path hover tooltip, Go-to-line input (`Full Preview`), `Find (Ctrl+F)` toggle, `Reload` button, and live `Dark` / `Light` theme toggle.
     - Fixed-width right-aligned monospace line-number gutter + horizontal/vertical virtualized `ScrollArea::show_rows`.
     - Bottom status bar displaying relative/full path, indexing progress or total/displayed line count, formatted byte size, detected encoding (`UTF-8`, `UTF-8 BOM`, `UTF-16 LE`, `UTF-16 BE`, `8-bit (lossy UTF-8)`), line-ending style (`LF` / `CRLF`), and `READ-ONLY` badge.

2. **Safe File Opening, TOCTOU Protection & Text Encodings (`apps/radivine-viewer/src/file_io.rs`):**
   - Opens files with `O_RDONLY | O_NONBLOCK | O_CLOEXEC` and verifies `fstat` on the opened file descriptor is a regular file (`S_IFREG`) before reading a single byte—never blocking on FIFOs, sockets, or device nodes and eliminating path-to-fd TOCTOU races.
   - Sniffs the first `8 KiB` for 23 binary magic signatures, NUL bytes, and control-byte ratios, rejecting binary files with exit code `3`.
   - Detects and decodes `UTF-8`, `UTF-8 BOM`, `UTF-16 LE` (2-byte aligned reads via `encoding_rs`), `UTF-16 BE` (2-byte aligned reads via `encoding_rs`), and `Unknown8Bit` (lossy UTF-8 replacement `\u{FFFD}` with a non-intrusive warning banner).

3. **Head & Tail Preview Engines (`apps/radivine-viewer/src/head_tail.rs`):**
   - **Head (`read_head`):** Streams forward in `64 KiB` chunks until `N` lines or the `8 MiB` safety cap (`MAX_HEAD_TAIL_SCAN_BYTES`), truncating individual display lines longer than `64 KiB` with `"…"`. Preserves exact raw line slices for byte-for-byte parity with GNU `head -n N`.
   - **Tail (`read_tail`):** Seeks to EOF and scans backwards in `64 KiB` blocks using `memchr::memrchr_iter` (ignoring a single final trailing newline when counting `N` lines) up to `N + 1` newlines, start-of-file, or `8 MiB` scanned. Computes exact 1-based line numbers when BOF is reached within the scan window. Cost is $O(\text{last } N \text{ lines})$, completely independent of total file size.

4. **Full Preview Engine (`apps/radivine-viewer/src/full.rs`):**
   - Uses chunked `FileExt::read_at` (`pread`) exclusively—**never `mmap`**—so concurrent file truncation by another process never raises `SIGBUS`.
   - Immediately reads the first `64 KiB` on open so the first screen renders in `< 1 ms` while a background thread (`radivine-viewer-indexer`) scans the file in `256 KiB` chunks with `memchr` to build a sparse line index (byte offset of every `1024`th line).
   - Maintains a 256-line sliding window cache populated via `pread` from the nearest sparse checkpoint for smooth 60 Hz virtualized scrolling in `egui::ScrollArea::show_rows`.
   - Periodically polls `fstat` on the open fd (`poll_disk_state_if_due` / `poll_disk_state_now`) to detect concurrent file truncation or modification, clamping the index and displaying a clear error/warning banner with a one-click `Reload` action (`AC-5.4`).

5. **Streaming Search Engine (`apps/radivine-viewer/src/search.rs`):**
   - Supports interactive Find (`Ctrl+F`, `Enter` for Next, `Shift+Enter` for Previous, `Esc` to close, `Aa` case-sensitivity toggle).
   - Streams the file in `1 MiB` (`1,048,576` B) chunks with `pattern.len() - 1` byte overlap between adjacent chunks using `memchr::memmem::Finder`, ensuring matches straddling chunk boundaries are never missed and matching `grep -c` / `grep -i -c` counts.

6. **Daemon & Action Integration (`crates/radivine-actions`, `apps/radivine`):**
   - Replaced M4 placeholders with `PreviewAction` (`radivine.preview.full`, `radivine.preview.head`, `radivine.preview.tail`), spawning `radivine-viewer` in a detached process group (`process_group(0)`).
   - Added `[preview] head_lines = 50` and `tail_lines = 50` to `AppConfig` (`apps/radivine/src/config.rs`) and wired hot-reload support via `radivine reload`.
