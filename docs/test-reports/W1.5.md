Date: 2026-10-27 UTC. Branch: `feat/website`. Started from `b67efa2` with a clean tree and W0/W1 already committed. The user explicitly authorized W1.5: homepage visual redesign and reusable motion components. No push or deployment occurred.

## Delivered experience

The homepage now follows a single visual idea: a point becoming a direction. Large masked typography and radial sectors assemble around the unchanged Radivine vine; a connecting path leads into a child wheel. The child wheel's open bridge faces its parent, informed by the application's branching geometry. Bounded desktop pointer motion adds depth without moving any controls. The lime accent is confined to the illustrated direction marker.

A four-stage workflow replaces the old three-column explanation. Files move aside as the wheel appears, a child opens as the reader reaches submenu navigation, and a completion mark resolves the illustrated action. A continuous progress line follows scrolling. The illustration stays beside the text on suitable desktop viewports; the scroll position remains entirely under browser/user control, and reversing direction reverses the sequence. Copy remains visible and meaningful throughout.

Three feature compositions give the page a different rhythm: layered paper and a drawn text highlight, branching format paths and staggered PNG/JPEG/WebP chips, and a wide configuration panel with sequential slider geometry. These are explicitly captioned visual studies, not application windows or functional controls. The closing invitation returns to drawn branching lines.

Light retains pale mint surfaces and deep green type; Dark uses forest surfaces and mint accents. The original green symbol sits on a pale mount in both. Text-bearing surfaces switch palettes atomically to avoid intermediate low contrast; decorative geometry transitions over 180 ms. The original Light/Dark/System initialization, persistence, OS updates, storage guards, and keyboard behavior are preserved.

[Motion and visual contract](../website/W1.5-motion.md) documents components, timings, easing, fallback behavior, and the W0 visual decisions superseded by W1.5.

## Performance and tradeoffs

[Measurements](media/W1.5/measurements.json) contain the final four local capture runs. They are unthrottled Chromium observations while recording video, not field data, a Lighthouse score, or low-end hardware certification. The small resource footprint and event-driven implementation are useful evidence, but cannot establish real-world INP or LCP.

The home contains **3,930 bytes raw / 1,456 bytes gzip JavaScript**, including existing theme/navigation code. There is no added dependency, animation framework, runtime image request to an external host, canvas renderer, or infinite loop. Illustrations use inline SVG, the original symbol's optimized derivative, and the existing local font. CSS is roughly 33 KB raw across built stylesheets. Geometry and image dimensions reserve layout space; measured CLS is zero in all four capture runs. Local recorded LCP ranged from 108–176 ms; the first Light desktop run recorded one 64 ms long task, while the other three recorded none. These numbers include capture overhead and are not production performance guarantees.

Tradeoffs:

- Desktop offers the richer sticky sequence. Mobile, short windows, and reduced motion prioritize a complete diagram and compact reading order. They do not attempt scroll-linked choreography offscreen.
- Reduced motion disables motion rather than substituting a smaller continuous effect. No JavaScript retains all information, with a complete static diagram.
- Text-bearing theme surfaces switch immediately; only decorative geometry blends. This gives contrast priority over a page-wide crossfade.
- No current native desktop captures were approved. Product illustrations are labeled, historic screenshots are unused, and the existing guide remains the destination for accurate application detail. There is no W3 interaction simulation.
- Pointer movement and hover depth are small and finite. No particles, perpetual rotation, excessive glow, or scroll hijacking were added.
