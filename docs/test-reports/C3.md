## 1. Summary of C3 Deliverables

### 1.1 Backwards-Compatible Core Extensions (`crates/radivine-core`, `1d23fca`)

  - Added default method `Action::description_for(&self, ctx: &BasicContext) -> Option<Cow<'_, str>>` in [`crates/radivine-core/src/action.rs`](../../crates/radivine-core/src/action.rs), defaulting to `self.meta().description.as_deref().map(Cow::Borrowed)`.
  - Updated `ActionRegistry::build_action_leaf` in [`crates/radivine-core/src/registry.rs`](../../crates/radivine-core/src/registry.rs) to call `action.description_for(&ctx.basic)` with zero breaking changes to existing `Action` implementations.
- **Explicit Uninspected `FileFacts` State (`E2`):**
  - Exported `CAP_EXCEEDED_REASON` (`"Batch cap (> 64 items) — not inspected"`) and `ENRICH_TIMEOUT_REASON` (`"Enrichment timed out"`) and added `FileFacts::cap_exceeded()` and `FileFacts::is_uninspected(&self) -> bool` in [`crates/radivine-core/src/context.rs`](../../crates/radivine-core/src/context.rs) and [`crates/radivine-core/src/enrich.rs`](../../crates/radivine-core/src/enrich.rs).
  - Preserved `PreviewAction` disabled behavior (`"Couldn't inspect the file"`) while allowing `ConvertAction` to distinguish uninspected items (`> 64` enrichment cap or timeout) from confirmed non-images (`AC-C3.2`).
- **Lossless Non-UTF-8 File URI Encoding (`E8`):**
  - Updated `local_path_to_file_uri(&Path)` in [`crates/radivine-core/src/context.rs`](../../crates/radivine-core/src/context.rs) to percent-encode raw `OsStrExt::as_bytes()` per path segment (`RFC 8089`) without lossy `U+FFFD` substitution.
  - Added `CliArg` trait for `normalize_cli_arg_to_uri` supporting `&str`, `String`, `Cow<'_, str>`, `&OsStr`, `OsString`, `&Path`, and `PathBuf`.

- **Codec-Free Built-in Catalog Descriptor (`crates/radivine-convert`):**
  - Added `BackendDescriptor::builtin_image()` and `CapabilityCatalog::default_builtin()` in [`crates/radivine-convert/src/backend.rs`](../../crates/radivine-convert/src/backend.rs) so `radivine-actions` and `apps/radivine` construct the default image capability catalog without depending on `radivine-convert-image`, `image`, `webp`, or `libwebp-sys2` (`AC-C3.10`).

  - Implemented `ConvertMenuContext`, `ConvertAction` (`radivine.convert.image.png`, `radivine.convert.image.jpeg`, `radivine.convert.image.webp`), and `register_convert_actions`.

  - Implemented progressive `enablement(&Context)` (`AC-C3.2`) and exact per-session captions (`AC-C3.3`) across single-image, homogeneous batch, mixed batch, already-target-format, unreadable, folder, broken-symlink, missing-file, `> 64`-item cap, and enrichment-timeout selections.
  - Wired `ConvertAction::run` to `JobsClient::connect_or_launch` and `JobsClient::submit_typed` (`Origin::Wheel`, `"convert.image"`), returning immediately once the durable worker job is accepted (`AC-C3.6`).
- **Menu Specification & Registry Constructors (`E3`, `E4`):**
  - Updated `default_menu()` in [`crates/radivine-actions/src/lib.rs`](../../crates/radivine-actions/src/lib.rs) to insert `radivine.convert` (`Convert ▸ Image ▸ {PNG, JPEG, WebP}`) at index `1` after `radivine.preview`. When no candidate images are selected, `ActionRegistry::build_menu` prunes `radivine.convert` completely (`AC-C3.1`).
  - Added `register_builtins_with_options` and `registry_from_options` while preserving all 6 existing registry constructors.
- **Mixed-Selection Skip Handling in Worker (`apps/radivine-worker/src/handler.rs`):**
  - Updated `plan_single_item` so non-image extensions (e.g. `notes.txt`, `clip.gif`) and directories included in a mixed batch selection from the wheel are recorded as `ItemState::Skipped` (`unsupported_format` / `not_regular_file`) while corrupt files with image extensions (e.g. `broken.png`) continue to fail with `ItemState::Failed` (`AC-C3.9` + C2 compatibility).

## 6. Owner Manual Desktop & Nemo Verification Plan (Safe & Reversible)

Per the strict desktop safety boundary, the running `radivine.service` and `/usr/bin/radivine` on your desktop were not modified. You can manually test Quick Convert in two ways:

### Option A — Zero-Disruption Isolated Invoke & Worker Test (Does NOT Stop `radivine.service`)

This runs the newly built `./target/release/radivine` and `./target/release/radivine-worker` against temporary sockets in `/tmp/radivine-c3-live` while displaying the real graphical X11 radial wheel on your monitor:

```bash
# 1. Build release binaries
cargo build --release -p radivine -p radivine-worker

# 2. Prepare an isolated test folder with sample PNG, JPEG, and text files
export RV_C3=/tmp/radivine-c3-live
rm -rf "$RV_C3"
mkdir -p "$RV_C3"/{run,state,config,photos}

python3 -c '
import os
from PIL import Image
d = os.environ["RV_C3"] + "/photos"
Image.new("RGBA", (640, 480), (40, 120, 220, 255)).save(f"{d}/vacation.png")
Image.new("RGB", (640, 480), (220, 100, 60)).save(f"{d}/portrait.jpg")
open(f"{d}/notes.txt", "w").write("sample text file\n")
'

# 3. Start an isolated C3 worker and an isolated C3 daemon (on a separate --socket so your live radivine.service is untouched)
RADIVINE_WORKER_BIN="$PWD/target/release/radivine-worker" \
RADIVINE_WORKER_SOCKET="$RV_C3/run/worker.sock" \
RADIVINE_WORKER_DB="$RV_C3/state/jobs.sqlite3" \
XDG_RUNTIME_DIR="$RV_C3/run" \
XDG_STATE_HOME="$RV_C3/state" \
XDG_CONFIG_HOME="$RV_C3/config" \
./target/release/radivine --socket "$RV_C3/run/radivine.sock" daemon >"$RV_C3/daemon.log" 2>&1 &
C3_DAEMON_PID=$!
sleep 0.5

# 4. Summon the real graphical wheel on a single PNG image:
#    Hover Convert -> Image -> WebP and click to convert!
./target/release/radivine --socket "$RV_C3/run/radivine.sock" invoke "$RV_C3/photos/vacation.png"

# 5. Inspect the created vacation.webp and worker job history:
ls -la "$RV_C3/photos"
./target/release/radivine-worker \
  --socket "$RV_C3/run/worker.sock" \
  --db "$RV_C3/state/jobs.sqlite3" \
  --lock "$RV_C3/run/worker.lock" \
  list

# 6. Summon the wheel on a mixed selection (PNG + JPG + WebP + TXT):
#    Hover Convert -> Image -> WebP (caption: "Convert 2 of 4 files to WebP · 1 already WebP · 1 not supported") and click!
./target/release/radivine --socket "$RV_C3/run/radivine.sock" invoke \
  "$RV_C3/photos/vacation.png" \
  "$RV_C3/photos/portrait.jpg" \
  "$RV_C3/photos/vacation.webp" \
  "$RV_C3/photos/notes.txt"

./target/release/radivine-worker \
  --socket "$RV_C3/run/worker.sock" \
  --db "$RV_C3/state/jobs.sqlite3" \
  --lock "$RV_C3/run/worker.lock" \
  show 2

# 7. Clean up the isolated C3 daemon and worker:
./target/release/radivine --socket "$RV_C3/run/radivine.sock" quit
wait "$C3_DAEMON_PID" 2>/dev/null || true
./target/release/radivine-worker \
  --socket "$RV_C3/run/worker.sock" \
  --db "$RV_C3/state/jobs.sqlite3" \
  --lock "$RV_C3/run/worker.lock" \
  shutdown-if-idle || true
```

### Option B — Live Nemo `Drag + Shift` Test & Instant Rollback Procedure

To test live `Drag + Shift` directly inside Nemo before C5 packaging installs the new binaries to `/usr/bin`:

```bash
# 1. Stop the currently running v0.1.1 systemd service temporarily:
systemctl --user stop radivine.service

# 2. Run the C3 release daemon in the foreground with RADIVINE_WORKER_BIN pointing to target/release/radivine-worker:
RADIVINE_WORKER_BIN="$PWD/target/release/radivine-worker" \
./target/release/radivine daemon
```

While `./target/release/radivine daemon` is running:
1. Open Nemo in `/tmp/radivine-c3-live/photos`.
2. Drag `vacation.png`, press `Shift` to summon the wheel, navigate `Convert ▸ Image ▸ WebP`, and release the mouse button.
3. Verify `vacation.webp` appears beside `vacation.png` in Nemo and a desktop notification `"Conversion complete"` is shown.
4. Drag `notes.txt`, press `Shift`, and verify `Convert` is not shown on text-only selections.

#### Rollback / Restore Procedure (Returns Immediately to `v0.1.1`)

```bash
# 1. Stop the foreground C3 test daemon (Ctrl+C or `radivine quit`) and stop any on-demand worker:
./target/release/radivine quit || true
./target/release/radivine-worker shutdown-if-idle || true

# 2. Restart your original v0.1.1 systemd service:
systemctl --user start radivine.service
systemctl --user status radivine.service
```
