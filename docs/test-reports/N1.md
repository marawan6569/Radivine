## 2. Files and APIs Changed

1. **`crates/radivine-wheel/src/config.rs` & `crates/radivine-wheel/src/lib.rs`**:
   - Added `pub enum WheelLayout { #[default] Branching, Concentric }`.
   - Added `pub layout: WheelLayout` to `WheelConfig` (default `WheelLayout::Branching`, preserved across `WheelConfig::validate()`).
   - Added `pub enum LayoutFallback { InsufficientSpace, TargetTooSmall, NoCompositor }`.
   - Added `pub struct LayoutSelection { pub requested: WheelLayout, pub effective: WheelLayout, pub fallback: Option<LayoutFallback> }` with `LayoutSelection::branching()`, `LayoutSelection::concentric()`, and `LayoutSelection::fallback_to_branching(reason)`.
   - Re-exported `WheelLayout`, `LayoutFallback`, and `LayoutSelection` from `radivine_wheel`.
   - Preserved `#![forbid(unsafe_code)]` and `smallvec` as the sole runtime dependency.
2. **`crates/radivine-wheel/src/session.rs`**:
   - Added `pub layout_selection: LayoutSelection` to `DebugState`.
   - Added private `LayoutState { Branching, Concentric(ConcentricState) }` and `ConcentricState` placeholder to `WheelSession` (no dynamic trait objects).
   - Added `WheelSession::layout_selection(&self) -> LayoutSelection`, `WheelSession::record_layout_fallback(&mut self, reason: LayoutFallback)`, `WheelSession::set_menu_at_pointer(&mut self, menu: MenuTree, pointer: Point, now: Millis)`, `WheelSession::set_enabled_at(&mut self, path: &ItemPath, enabled: bool, disabled_reason: Option<Arc<str>>, now: Millis)`, and `WheelSession::suspend_interaction(&mut self, now: Millis)`.
   - Isolated layout-dependent entry points (`handle_pointer_moved`, `handle_pointer_release`, `handle_nav_key`, `tick` interactive timers, `drop_target`, `next_deadline`, `rebuild_input_region`, `rebuild_scene`) behind `LayoutState` dispatch without altering any Branching math, timings, or transitions.
3. **`apps/radivine/src/config.rs`**:
   - Added `WheelSection.layout: String` (default `"branching"`) with tolerant `toml::Value` deserializer (`deserialize_wheel_layout`) that preserves strings for validation and converts non-string TOML types (`integer`, `float`, `boolean`, `array`, `table`, `datetime`) into an internal invalid-type sentinel.
   - Updated `AppConfig::sanitize(&mut self)` to log a warning and reset **only** `wheel.layout` to `"branching"` when not `"branching"` or `"concentric"`, leaving all other `[wheel]`, `[trigger]`, `[input]`, `[preview]`, `[appearance]`, `[notifications]`, and `[x11]` fields intact.
   - Updated `AppConfig::validate_strict(&self)` to require exact `"branching"` or `"concentric"` without case folding or whitespace trimming, rejecting both invalid strings and the non-string TOML sentinel.
   - Updated `AppConfig::to_wheel_config(&self, reduced_motion: bool)` to map `"concentric"` to `WheelLayout::Concentric` and `"branching"` (or fallback) to `WheelLayout::Branching`.
4. **`apps/radivine/tests/nested_config.rs` & `crates/radivine-wheel/tests/unit_tests.rs`**:
   - Added `T-CFG1`..`T-CFG4` compatibility and strict-validation tests in `apps/radivine/tests/nested_config.rs` and unit test in `apps/radivine/src/config.rs`.
   - Added `test_n1_layout_selection_state_and_fallback_queries` and `test_t_reg1_branching_deterministic_baseline_traces` in `crates/radivine-wheel/tests/unit_tests.rs`.
