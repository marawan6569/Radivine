### 1.3 Security Audit & 2×10-Minute Continuous Fuzzing (`AC-6.4`, `57a0ac2`)
- **Bug Found & Fixed During Fuzzing (`crates/radivine-core/src/context.rs`):**
  - Fuzzing `parse_uri_list` + `BasicContext::from_uris` immediately discovered that a `file:///...` URI containing a literal or percent-encoded NUL byte (`\0` / `%00`) produced a `PathBuf` with an interior NUL byte. Fixed `parse_file_uri_to_local_path` to reject any decoded path containing `0x00` (`if decoded_bytes.first() != Some(&b'/') || decoded_bytes.contains(&0) { return None; }`).
- **Automated `unsafe` & Security Audit (`apps/radivine/tests/m6_fuzz_suite.rs`):**
  - Verified `#![forbid(unsafe_code)]` in `radivine-wheel`, `radivine-render`, `radivine-actions`, and `radivine-viewer`.
  - Scanned all `.rs` source files across `crates/`, `apps/`, and `tools/` and verified that `unsafe` blocks exist only in `crates/radivine-platform/src/x11/shm.rs` (3 POSIX `shmget`/`shmat`/`shmdt` calls) and `apps/radivine/src/main.rs` (1 `BorrowedFd::borrow_raw` call for `calloop`).
- **2×10-Minute Continuous Fuzzing Results (`RADIVINE_FUZZ_SECONDS=600`):**
  - **Phase 1 (`parse_uri_list` + `BasicContext::from_uris` + `sniff_bytes`):** Ran for **`600 s` (`10 min`)**, executing **`252,196,000` iterations** with **`0` panics** and **`0` memory-safety violations**.
  - **Phase 2 (`XdndTarget` + `SelectionReader` + `parse_actions_toml`):** Ran for **`600 s` (`10 min`)**, executing **`239,423,000` iterations** with **`0` panics** and **`0` memory-safety violations**.

## 3. Remaining Clean-VM Verification Steps (Section 9 Draft Release Policy)

Because installing system-wide `.deb` packages onto the project owner's live workstation is prohibited (Section 6 & Section 13) and `Xvfb` / a separate Linux Mint VM is not available inside this environment, the GitHub release is prepared as a **Draft Release** (`Radivine v0.1.0 — Initial Release`) with `radivine_0.1.0_amd64.deb` and `SHA256SUMS.txt` attached.

To perform the final clean-VM package installation smoke test before clicking **Publish release** on GitHub:

```bash
# Inside a clean Linux Mint 22.x (Cinnamon X11) VM:
sha256sum -c SHA256SUMS.txt
sudo apt install ./radivine_0.1.0_amd64.deb

# Verify doctor, daemon, Nemo action, and viewer:
radivine doctor
radivine daemon &
radivine status
radivine invoke /etc/hosts
radivine quit

# Verify clean uninstallation:
sudo apt remove -y radivine
which radivine || echo "Cleanly removed"
```
