## 1. Summary of C2 Deliverables

### 1.1 Standalone D-Bus Wire-Protocol Client (`crates/radivine-dbus`, `d446afa`)
- Extracted the pure-Rust D-Bus session-bus wire-protocol client from `crates/radivine-actions/src/dbus.rs` into [`crates/radivine-dbus`](../../crates/radivine-dbus/src/lib.rs) (`#![forbid(unsafe_code)]`, depends only on `thiserror` at runtime) as specified by extension `E6` (`SYSTEM_INTEGRATION.md` §1, `ADR-027`).
- Added `call_show_items` (`org.freedesktop.FileManager1.ShowItems`) alongside `call_desktop_notify` (`org.freedesktop.Notifications.Notify`) and `call_portal_trash_file` (`org.freedesktop.portal.Trash.TrashFile`).
- Re-exported `radivine_dbus::*` from `crates/radivine-actions/src/dbus.rs` with zero public API breakage.

### 1.2 C2 Conversion Core & Backend Hooks (`crates/radivine-convert`, `crates/radivine-convert-image`, `e2c5139`)
- Added non-UTF-8 stem preservation (`resolve_output_destination_os`, `derive_suffixed_filename_os`, `PendingOutput::commit_with_policy_os`) so Unix filenames containing arbitrary non-UTF-8 bytes (`0x80`, `0xFF`) preserve their exact stem bytes into the converted output filename (`AC-C2.16`).
- Added `CommitRequest.attempt`, `is_canonical_stage_dir_name`, `PendingOutput::disarm_drop_cleanup` (for watchdog-fenced timeout deferral to startup recovery), `ConversionError::code()`, and `ErrorClass::as_str()`.
- Scaled per-item `image::Limits.max_alloc` in `crates/radivine-convert-image` to `max(limits.max_alloc_bytes, 4 * width * height)` after `max_pixels` validation so valid `64 MP`–`100 MP` images (`256 MiB`–`400 MiB` RGBA) admitted under `ResourceGovernor` exclusive mode are not prematurely rejected at `256 MiB`.

### 1.3 Generic Background Job Contracts, `WirePath`, IPC Protocol v1 & Launcher (`crates/radivine-jobs`, `8251bd1`)
- Implemented [`crates/radivine-jobs`](../../crates/radivine-jobs/src/lib.rs) (`#![forbid(unsafe_code)]`, zero dependency on conversion crates, X11, or UI):
  - `wire_path.rs`: Lossless ASCII percent-encoded `WirePath` (`%` always encoded as `%25`, rejecting empty paths, NUL bytes, relative paths, and decoded paths `> 4,096` bytes), verified with `proptest` across arbitrary `[u8]` sequences (`0x01..=0xFF`).
  - `state.rs`: `JobId`, `RequestId` (`16..=64` ASCII `[0-9a-zA-Z_-]`), `Origin` (`Wheel`, `Cli`, `ControlCenter`, `Test`), `RetryMode` (`FailedOnly`, `FailedAndCancelled`, `All`), `JobState` (`Queued`, `Preparing`, `Running`, `Completed`, `CompletedWithErrors`, `Failed`, `Cancelled`), `ItemState` (`Pending`, `Inspecting`, `Running`, `Committing`, `Succeeded`, `Skipped`, `Failed`, `Cancelled`, `Interrupted`), `compute_terminal_job_state`, and table-driven transition validation (`55` cases `>= 40`, `AC-C2.3`).
  - `protocol.rs`: Versioned (`"v": 1`) JSON-lines IPC frames (`WorkerRequest`, `WorkerResponse`, `JobUpdate`, `WorkerErrorCode`) and pre-allocation-bounded `read_bounded_line` / `read_worker_request` (`16 MiB` max for `submit`, `64 KiB` max for non-`submit` commands, `4 MiB` max for responses).
  - `settings.rs`: `[jobs]` section parser (`JobsSettings`, `JobsNotifyPolicy`) with lenient clamping and `[notifications] enabled` cross-section awareness.
  - `client.rs`: `WorkerRuntimePaths`, `WorkerLaunchMode`, `WorkerLauncher` (`systemctl --user start` -> `systemd-run --user --collect` transient unit -> detached `process_group(0)` spawn with `2 MiB` log rotation), `JobsClient` (with automatic keep-alive reconnect), and push `Subscription`.

### 1.4 Standalone Durable Background Worker & CLI (`apps/radivine-worker`, `packaging/radivine-worker.service`, `29357d0`, `4cd0486`)
- Implemented [`apps/radivine-worker`](../../apps/radivine-worker/src/lib.rs) (`#![forbid(unsafe_code)]`, `clippy.toml` disallowing `std::fs::rename`):
  - `server.rs`: Single-instance `worker.lock` (`O_CREAT | O_RDWR | O_CLOEXEC`, `0600`, `flock(LOCK_EX | LOCK_NB)`), `0600` `worker.sock` with `SO_PEERCRED` UID verification, race-free two-phase idle shutdown (Phase 1 `unlink(worker.sock)`, Phase 2 drain re-accepting any in-flight `connect()` before `PRAGMA wal_checkpoint(TRUNCATE)` and exit `0`), and graceful `SIGTERM`/`SIGINT` drain (`<= 5 s`).
  - `store.rs`: SQLite WAL `JobStore` (`rusqlite` bundled SQLite, `journal_mode = WAL`, `foreign_keys = ON`, `busy_timeout = 5000`, `synchronous = NORMAL` default with `PRAGMA synchronous = FULL` barriers for `C0a`, `C0b`, `C1`, `C2`, and `C5`/`C6` recovery commits), `request_id` idempotency, retention pruning (`retention_max_jobs`, `retention_days`), and `BLOB` storage for `source_path`, `output_path`, `temp_path`, and `stage_dir_path`.
  - `recovery.rs`: Complete `C0a`–`C6` startup crash recovery and `/proc/sys/kernel/random/boot_id` reconciliation executed before binding `worker.sock`.
  - `governor.rs`: Memory-budgeted `ResourceGovernor` with FIFO ticket queue, exclusive single-item mode for oversized items (`memory_budget_bytes < needed <= worker_memory_max_bytes`), drain mode, and `statvfs` destination free-space prechecks (`2 * temp_disk_bytes + 32 MiB`).
  - `fence.rs`: Lock-free-I/O `Mutex<ItemPhase>` 3-step `acquire_commit_permit` commit fence (`Step A` `O(1)` lock -> `Step B` unlocked `PRAGMA synchronous = FULL` SQLite `Committing` write -> `Step C` `O(1)` lock verification) + `InFlightItemSlot` watchdog coordination.
  - `scheduler.rs`: Round-robin multi-job scheduler (`K = 4` consecutive items per job before rotating), `<= 10 Hz` (`100 ms`) `EventHub` progress coalescing with slow/disconnected subscriber pruning, 3-consecutive-`ENOSPC`/`EACCES` batch short-circuit, and per-item watchdog thread with `exit(75)` (`EX_TEMPFAIL`) worker recycling and replacement worker handoff.
  - `handler.rs` & `notify.rs`: Generic `JobHandler` trait, built-in `ConvertImageHandler` (`"convert.image"`), and `radivine-dbus` desktop completion notifications (`all | errors_only | off`).
  - `main.rs`: Developer and management CLI (`serve`, `status`, `list`, `show`, `cancel`, `retry`, `submit-convert`, `shutdown-if-idle`).
  - [`packaging/radivine-worker.service`](../../packaging/radivine-worker.service): Static systemd user unit definition (`Type=simple`, `Restart=on-failure`, `RestartForceExitStatus=75`, `MemoryHigh=768M`, `MemoryMax=1G`, `CPUQuota=200%`, `Nice=10`, `IOSchedulingClass=best-effort`, `IOSchedulingPriority=6`, `NoNewPrivileges=yes`, `PrivateTmp=yes`, `ProtectSystem=strict`). Not installed or enabled on the owner's live desktop in C2.

## 3. Crash-Recovery (`C0a`–`C6`) & Watchdog Evidence

| Crash / Fence Scenario | Injected Fault | Verified Post-Recovery State |
|---|---|---|
| **`C0a`** | `abort()` after `stage_dir_path` intent journaled (`PRAGMA synchronous = FULL`), before `mkdirat` | Item marked `Interrupted(worker_crashed)`; `stage_dir_path` cleared; `0` `.rvstage-*` directories on disk; subsequent `retry` succeeds (`attempt_count = 2`). |
| **`C0b`** | `abort()` after `mkdirat(.rvstage-*)` + `fsync(dest_dir)`, before `(stage_dev, stage_ino)` journaled | Recovery verifies empty canonical `.rvstage-*` directory, `rmdir`s it, `fsync`s parent dir, marks item `Interrupted(worker_crashed)`; `0` `.rvstage-*` remain. |
| **`C1_unjournaled`** | `abort()` after `openat(O_CREAT\|O_EXCL)` of `.part`, before `(temp_path, temp_dev, temp_ino)` journaled | Per `INV-RECOVERY-OWNERSHIP`, unjournaled file is **not** unlinked by pattern; `Warning::OrphanedTempPreserved` is recorded on the item and item is marked `Interrupted(worker_crashed)`. |
| **`C1`** | `abort()` after `(temp_path, temp_dev, temp_ino)` journaled (`PRAGMA synchronous = FULL`), during write | Recovery verifies `(stage_dev, stage_ino)` and `(temp_dev, temp_ino)`, unlinks `.part`, removes empty `.rvstage-*`, marks item `Interrupted(worker_crashed)`. |
| **`C2`** | `abort()` after `Committing` + candidate `output_path` journaled (`PRAGMA synchronous = FULL`), before `commit_no_replace` | Recovery sees `output_path` absent, verifies and unlinks `.part`, removes empty `.rvstage-*`, marks item `Interrupted(worker_crashed)`. |
| **`C3`** | Rung B `abort()` after `linkat(temp -> output)` + `fsync(dest_dir)`, before `unlinkat(temp)` | Recovery verifies `output_path` has `(dev, ino) == (temp_dev, temp_ino)` and `size > 0`, unlinks leftover hardlinked `.part`, removes `.rvstage-*`, and promotes item to **`Succeeded`** (`JobState::Completed`). |
| **`C4`** | `abort()` after `renameat2(RENAME_NOREPLACE)` + `fsync(dest_dir)`, before `Succeeded` SQLite commit | Recovery verifies `output_path` has `(dev, ino) == (temp_dev, temp_ino)` and `size > 0`, removes `.rvstage-*`, and promotes item to **`Succeeded`** (`JobState::Completed`). |
| **`C5`** | `abort()` after `Succeeded` SQLite commit, before `rmdir(.rvstage-*)` and before clearing `stage_dir_path` | Recovery removes verified empty `.rvstage-*`, clears `stage_dir_path`, and preserves item **`Succeeded`** (`JobState::Completed`). |
| **`C6`** | `abort()` after item `Succeeded` SQLite commit, before parent `jobs.state` transitions from `running` to `completed` | Recovery recomputes parent job counts and transitions parent job from `Running` to **`Completed`**. |
| **`T-WATCHDOG-FENCE` & `T-WATCHDOG-LOCK-NONBLOCKING`** | Step B (`PRAGMA synchronous = FULL` SQLite `Committing` write) stalled for `500 ms` while watchdog fires at `80 ms` | Watchdog acquires `Mutex<ItemPhase>` in **`< 1 ms`** (`< 5 ms` budget), marks `ItemPhase::TimedOut`, and Step C refuses to issue `CommitPermit` (`Err(Limit::Timeout)`). |
| **`T-WATCHDOG-COLLISION-FENCE`** | Attempt 0 acquires `CommitPermit`, watchdog fires during `InCommit(0)` (`timeout_observed = true`), attempt 0 returns `EEXIST`, attempt 1 calls `acquire_commit_permit` | Step A of attempt 1 immediately aborts with `Limit::Timeout` and never journals or publishes attempt 1 (`a (1).webp`). |

## 4. Developer CLI Walkthrough & Manual Testing Commands

All commands below use an isolated temporary directory (`/tmp/radivine-c2-demo`) so they never touch your live desktop session or `~/.local/state/radivine`:

```bash
# 1. Build the worker and CLI Tools
cargo build -p radivine-worker -p convert-cli

# 2. Create an isolated workspace and sample test images
mkdir -p /tmp/radivine-c2-demo
./target/debug/convert-cli bench --warmup 0 --runs 1 >/dev/null 2>&1 || true
python3 -c '
from PIL import Image
for i in range(1, 6):
    img = Image.new("RGBA", (320, 240), (i * 40, 100, 200, 255))
    img.save(f"/tmp/radivine-c2-demo/sample_{i}.png")
'

# 3. Check worker status before starting (reports offline / on-demand idle)
./target/debug/radivine-worker \
  --socket /tmp/radivine-c2-demo/worker.sock \
  --db /tmp/radivine-c2-demo/jobs.sqlite3 \
  status

# 4. Submit a conversion job (automatically launches the background worker on demand!)
./target/debug/radivine-worker \
  --socket /tmp/radivine-c2-demo/worker.sock \
  --db /tmp/radivine-c2-demo/jobs.sqlite3 \
  submit-convert --to webp --wait /tmp/radivine-c2-demo/sample_*.png

# 5. List jobs and inspect per-item details
./target/debug/radivine-worker \
  --socket /tmp/radivine-c2-demo/worker.sock \
  --db /tmp/radivine-c2-demo/jobs.sqlite3 \
  list

./target/debug/radivine-worker \
  --socket /tmp/radivine-c2-demo/worker.sock \
  --db /tmp/radivine-c2-demo/jobs.sqlite3 \
  show 1

# 6. Shut down the isolated test worker cleanly when idle
./target/debug/radivine-worker \
  --socket /tmp/radivine-c2-demo/worker.sock \
  --db /tmp/radivine-c2-demo/jobs.sqlite3 \
  shutdown-if-idle
```
