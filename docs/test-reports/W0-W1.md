## Required Rust checks and limits

The website does not modify Rust. Repository-required checks were attempted with the installed Rust 1.99.1 toolchain (CI's reference remains 1.95.0):

- `cargo fmt --all --check`: passed.
- `cargo clippy --workspace --all-targets -- -D warnings`: failed at the same pre-existing `crates/radivine-render/src/lib.rs:1392` `chunks_exact_to_as_chunks` diagnostic recorded in the planning audit. No fix or suppression made.

Later workspace binaries, including previously noted environment-specific Arabic font tests, were not reached; no complete-workspace pass is claimed and no unrelated repairs were attempted.

Browser automation does not certify manual screen-reader behavior, actual browser zoom, touch hardware, Safari/Firefox, forced-colors rendering, application desktop compatibility, or public hosting. A 640px viewport is only a 200%-zoom reflow proxy. Lighthouse/field LCP/INP/CLS and external download checks remain future validation work.
